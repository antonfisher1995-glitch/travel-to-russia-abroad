# Travel to Russia Abroad

Russian-from-English learning app with 2,800 vocabulary entries organized into CEFR-style levels A1, A2, B1, and B2.

## Included features

- Vocabulary library with search and level/topic filters
- Flashcards, typing, translation, matching, and randomized multiple-choice vocabulary quiz
- Browser text-to-speech pronunciation for Russian
- Writing practice notes
- Local browser progress and progress export
- Citizenship study practice area and history/law topic outline
- GitHub Pages deployment workflow

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Publish through GitHub Pages

1. Upload the contents of this project folder to the repository's `main` branch.
2. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source.
3. Open **Actions** and wait for **Deploy to GitHub Pages** to finish with a green check.
4. Your project site URL will be `https://YOUR-GITHUB-USERNAME.github.io/travel-to-russia-abroad/`.

A new commit to `main` triggers another deployment.

## Progress and privacy

Progress is saved in the browser's local storage on the device being used. It is not synced between devices or accounts. Use the Export button to download a backup.

## Exam content note

The citizenship/history/law area is study practice, not an official exam, legal advice, or a guarantee of passing. Check current requirements and materials with an authorized examination center. Historical and legal facts should be independently reviewed and sourced before treating the content as authoritative.
